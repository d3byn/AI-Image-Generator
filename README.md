# AI Image Generator

A simple AI Image Generator web app using HTML, CSS, and JavaScript to generate AI images from text prompts using RapidAPI.

## Features

- Generate AI images from prompts
- Multiple image styles
- Different aspect ratios
- Download generated images
- Responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```bash
├── index.html
├── style.css
├── script.js
```

## Setup

1. Clone the repository

```bash
git clone <your-repo-link>
```

2. Open the project folder

3. Add your RapidAPI key inside `script.js`

4. Run `index.html`

## API Used

RapidAPI AI Text to Image Generator API
[link : https://rapidapi.com/poorav925/api/ai-text-to-image-generator-flux-free-api ]
